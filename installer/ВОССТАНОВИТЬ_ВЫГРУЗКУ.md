# Восстановление данных, полученных от врача

Не восстанавливайте пилотную выгрузку поверх `mis_nephrology_v2`.

1. Распакуйте `MIS_Pilot_Export_....zip` в закрытую локальную папку.
2. Проверьте SHA-256 `database.backup` по значению из `manifest.json`.
3. Создайте отдельную базу:

```bat
createdb -U postgres mis_nephrology_pilot_returned
```

4. Восстановите снимок:

```bat
pg_restore -U postgres --no-owner --no-privileges --exit-on-error -d mis_nephrology_pilot_returned database.backup
```

5. Проверьте количество пациентов и приёмов по `manifest.json`.
6. Подключайте приложение к этой базе только через отдельный временный `.env`.
7. После проверки решайте, какие записи переносить в основную базу. Автоматическое слияние двух баз этим комплектом намеренно не выполняется.

Выгрузка содержит полные медицинские записи и должна храниться как конфиденциальная медицинская информация.
