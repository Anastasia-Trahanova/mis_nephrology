# МИС Нефрология — комплект сборки пилотного установщика

Этот комплект добавляет в проект только папку `installer/`. Медицинская логика приложения, SQL-схема и интерфейс не изменяются.

Итог сборки на компьютере разработчика:

```text
installer\output\MIS_Nephrology_Pilot_Setup.exe
```

Это один Windows EXE. В него локально включаются:

- автономный runtime Python-приложения;
- локальный PostgreSQL 18;
- снимок выбранной PostgreSQL-базы;
- каталог исходных архивных DOC/DOCX/PDF;
- временные пароли тестовых учётных записей;
- памятка тестировщика;
- команды запуска, остановки и полной выгрузки данных пилота.

## Что устанавливается у врача

Приложение устанавливается в:

```text
C:\Program Files\MIS Nephrology Pilot
```

Данные хранятся отдельно:

```text
C:\ProgramData\MIS Nephrology Pilot
```

Приложение слушает только:

```text
http://127.0.0.1:8000
```

Встроенный PostgreSQL слушает только:

```text
127.0.0.1:55432
```

Установщик не создаёт сетевые правила и не открывает доступ другим компьютерам. Доступ с другого компьютера невозможен, пока код и конфигурация специально не изменены.

## Перед первой сборкой

1. Распакуйте папку `installer` в корень проекта. Должно получиться:

```text
D:\python\ckd\mis_for_registrations\installer\СОБРАТЬ_УСТАНОВЩИК.cmd
```

2. Убедитесь, что изменения проекта запушены и рабочая копия актуальна:

```bat
git status --short
```

3. В `.env` должна быть указана база, снимок которой попадёт врачу:

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_NAME=mis_nephrology_v2
DB_USER=postgres
DB_PASSWORD=...
ARCHIVE_DOCUMENTS_ROOT=D:/python/ckd/nephro_consultation_preparer/medical_archive
```

4. Активируйте рабочее виртуальное окружение проекта:

```bat
venv\Scripts\activate
```

5. Пароль можно не задавать вручную. При первой сборке будет создан файл:

```text
installer\private\pilot_credentials.env
```

В нём будет временный общий пароль для тестовых учёток. Этот файл исключён из Git.

Чтобы задать свой временный пароль заранее:

```bat
copy installer\private\pilot_credentials.env.example installer\private\pilot_credentials.env
notepad installer\private\pilot_credentials.env
```

## Сборка

Запустите двойным щелчком:

```text
installer\СОБРАТЬ_УСТАНОВЩИК.cmd
```

Или из CMD:

```bat
installer\СОБРАТЬ_УСТАНОВЩИК.cmd
```

Сборщик последовательно:

1. запускает стандартный `pytest`;
2. проверяет PostgreSQL 18;
3. проверяет базу и роли пользователей;
4. проверяет сохранённые `doctor_id` у клинических учёток;
5. проверяет наличие и SHA-256 архивных документов;
6. создаёт `pg_dump` базы в custom format;
7. копирует локальный PostgreSQL runtime;
8. копирует медицинский архив;
9. создаёт хеши временных паролей;
10. собирает автономный runtime через PyInstaller;
11. при отсутствии Inno Setup пытается установить его через `winget`;
12. собирает единый установщик.

Первая сборка требует интернета для установки сборочных библиотек, Inno Setup и Microsoft Visual C++ Runtime. Компьютеру врача интернет для установки не требуется.

## Результат

После успешной сборки появятся:

```text
installer\output\MIS_Nephrology_Pilot_Setup.exe
installer\output\Памятка_тестировщика_МИС.html
installer\output\build_manifest.json
```

`Памятка_тестировщика_МИС.html` содержит фактические логины и временные пароли, попавшие в конкретную сборку.

## Учётные записи

Сохраняются старые логины и связи с врачами:

```text
admin26_08
zakharova_m
kazarkin_d
vozova_a
lobanova_n

```

Для существующих пользователей меняется только `users.password_hash`. Роли, `doctor_id`, расписание, карточки и медицинские записи не меняются. `admin26_08` создаётся, если его нет.

## Проверка готового EXE

Перед передачей врачу проверьте установщик на отдельной чистой Windows 10/11 x64 или в виртуальной машине:

1. На тестовой машине не должны быть нужны Python и PostgreSQL.
2. Запустите `MIS_Nephrology_Pilot_Setup.exe`.
3. Подтвердите запрос UAC.
4. Дождитесь восстановления базы. Большой архив может устанавливаться долго.
5. После установки откроются памятка и страница входа.
6. Войдите под несколькими ролями.
7. Откройте архивный приём и скачайте исходный документ.
8. Создайте тестового пациента и приём.
9. Перезагрузите компьютер и снова запустите ярлык «МИС Нефрология».
10. Проверьте пункт «Выгрузить данные тестирования».

## Как врач возвращает результаты пилота

В меню «Пуск»:

```text
МИС Нефрология — пилот → Выгрузить данные тестирования
```

Появится файл:

```text
Документы\MIS_Pilot_Exports\MIS_Pilot_Export_YYYY-MM-DD_HH-MM-SS.zip
```

В ZIP находятся:

- `database.backup` — полное состояние PostgreSQL;
- `manifest.json` — контрольная сумма и количество записей;
- журналы приложения и базы;
- инструкция по восстановлению.

`database.backup` включает пациентов, приёмы, анамнез, жалобы, осмотр, анализы, расчёты, диагнозы, назначения, расписание, пользователей и аудит.

Исходные архивные документы по умолчанию повторно не дублируются, потому что они уже есть в исходной сборке. Для полной копии вместе с документами есть отдельный пункт:

```text
Выгрузить данные и архивные документы
```

## Повторная установка и удаление

Повторный запуск установщика обновляет программные файлы, но не перезаписывает уже инициализированную базу врача.

Удаление программы останавливает процессы и удаляет приложение, но намеренно сохраняет данные в:

```text
C:\ProgramData\MIS Nephrology Pilot
```

Это защищает результаты пилота от случайной потери. После получения и проверки выгрузки папку можно удалить вручную.

## Безопасность

Установщик, памятка и выгрузки содержат медицинские данные и временные пароли.

- Не загружайте `installer/output` и `installer/work` в GitHub.
- Не отправляйте установщик и выгрузки обычной электронной почтой.
- Используйте выделенный тестовый компьютер с шифрованием диска и отдельной учётной записью Windows.
- Не оставляйте памятку с паролями в общедоступной папке.
- После пилота смените или заблокируйте временные пароли.
- Не восстанавливайте полученную базу поверх основной; используйте отдельную проверочную базу.

## Диагностика

Журнал установки и runtime:

```text
C:\ProgramData\MIS Nephrology Pilot\logs\runtime.log
```

Журналы PostgreSQL:

```text
C:\ProgramData\MIS Nephrology Pilot\logs\postgres
```

Если порт `8000` или `55432` занят, приложение сообщит об ошибке. Освободите порт и повторите запуск.
